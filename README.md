Este proyecto fue desarrollado en C++ estándar y debe ser compilado utilizando `g++`.

## Para compilar: 
Abre la terminal, asegúrate de estar ubicado en la carpeta raíz del proyecto (donde se encuentran todos los archivos `.cpp` y `.h`) y ejecuta el siguiente comando:
```bash
g++ *.cpp -o hospital
```
## Para ejecutar:

En la misma terminal, escribes el comando:
```bash
.\hospital
```

Y si hiciste bien todo, el código se ejecutaría sin problemas!
